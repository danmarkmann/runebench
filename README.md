# RuneBench playground

Experiments with [RuneBench](https://github.com/MaxBittker/runebench), focused on running an agent and watching it play RuneScape.

Inspired by [this talk](https://www.youtube.com/watch?v=cNm4zyUtWj0).

## Run

```powershell
npm install
npm start
```

Uses the RS-SDK demo server and your existing `codex login`. Watch the game tab and follow the agent in the terminal. Stop with `npm stop` or Ctrl+C.

For a different task: `npm start -- "Catch and cook some shrimp."`
